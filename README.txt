CHART TECHNICAL ANALYSIS — SIMPLE FREE TEMPLATE

Αυτό είναι η απλή έκδοση που ζήτησες:
- Μία αρχική σελίδα.
- Επάνω: Αποποίηση Ευθύνης / Αρχική / Επικοινωνία.
- Εισαγωγικό κείμενο.
- 4 παράθυρα: Δείκτες / Μετοχές / Ξένοι Δείκτες / Κρύπτο.
- Drag & drop για εικόνες σε κάθε κατηγορία.
- Οι εικόνες αποθηκεύονται τοπικά στον browser μέσω IndexedDB.
- Δεν υπάρχουν άλλα περιττά sections.

ΣΗΜΑΝΤΙΚΟ:
Το drag & drop στην παρούσα δωρεάν έκδοση αποθηκεύει τις εικόνες στον browser του υπολογιστή που τις ανεβάζει.
Για να ανεβάζεις εικόνες και να εμφανίζονται δημόσια σε όλους τους επισκέπτες, χρειάζεται online αποθήκευση/backend (π.χ. Supabase/Firebase/Cloudinary ή hosting με CMS).
